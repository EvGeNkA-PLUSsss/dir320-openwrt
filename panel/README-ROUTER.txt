=====================================================================
 OpenWrt — памятка (создано универсальным установщиком)
=====================================================================

САЙТ И ПАНЕЛЬ
-------------
  Сайт    : http://<IP-роутера>/            (папка /srv/www)
  Панель  : http://<IP-роутера>/admin       (пароль = пароль root)
  LuCI    : http://<IP-роутера>:<порт>/     (порт смотрите в uci show uhttpd)
  Файлы панели:
    /srv/www/cgi-bin/admin         — панель (Lua CGI)
    /usr/libexec/panel-console.sh  — обёртка консоли
    /srv/www/index.html            — главная сайта
    /srv/www/admin/index.html      — редирект /admin/ → /cgi-bin/admin

FTP (vsftpd)
------------
  ftp://<IP-роутера>/   логин: ftpuser   пароль: ПАРОЛЬ ROOT
  FTP-корень = /srv/www (та же папка, что у сайта): загрузил по FTP —
  файл сразу доступен на сайте.
  Пароль FTP синхронизируется с root:
    - при установке в /etc/shadow копируется хеш root;
    - смена пароля через панель обновляет оба;
    - /usr/libexec/owinst-sync-ftp.sh по cron раз в 2 минуты
      чинит расхождение, если пароль меняли через LuCI/SSH.
  passive 50000-50100

СЛУЖБЫ
------
  /etc/init.d/uhttpd      — веб-сервер (сайт + LuCI, два инстанса)
  /etc/init.d/vsftpd      — FTP (procd)
  /etc/init.d/firewall    — правила для сайта, админки, FTP
  /etc/init.d/cron        — синхронизация FTP-пароля

ПОЛЕЗНЫЕ КОМАНДЫ
----------------
  sh /root/openwrt-installer.sh            — установщик (повторный запуск безопасен)
  sh /root/openwrt-installer.sh --status   — статус
  sh /root/openwrt-installer.sh --detect   — кандидаты на очистку (TSV)
  logread | grep uhttpd                    — логи веб-сервера
  iwinfo                                   — состояние Wi-Fi
  uci show uhttpd                          — конфиг веб-сервера

ОЧИСТКА СИСТЕМЫ
---------------
  Выполняется автоматически при установке: пакеты-листья по графу
  зависимостей (защищены запущенные службы/процессы, загруженные модули
  ядра, критичные компоненты), файлы без владельца, пустые каталоги,
  кеши opkg.

ПАРОЛИ
------
  root / LuCI / SSH / панель / FTP — один пароль.
  Wi-Fi (SSID/пароль) настраивается в панели → вкладка «Wi-Fi».
