=====================================================================
 D-Link DIR-320 B1 / OpenWrt 19.07 — памятка
 (создано установщиком dir320-tui.sh)
=====================================================================

САЙТ И ПАНЕЛЬ
-------------
  Сайт    : http://192.168.1.1/            (папка /srv/www)
  Панель  : http://192.168.1.1/admin       (пароль = пароль root)
  LuCI    : http://192.168.1.1:8080/
  Файлы панели:
    /srv/www/cgi-bin/admin         — панель (Lua CGI)
    /usr/libexec/panel-console.sh  — обёртка консоли
    /srv/www/index.html            — главная сайта
    /srv/www/admin/index.html      — редирект /admin/ → /cgi-bin/admin

FTP (vsftpd)
------------
  ftp://192.168.1.1/   логин: ftpuser   пароль: ПАРОЛЬ ROOT
  FTP-корень = /srv/www (та же папка, что у сайта): загрузил по FTP —
  файл сразу доступен на сайте.
  Пароль FTP синхронизируется с root:
    - при установке копируется хеш root в /etc/shadow;
    - смена пароля через панель обновляет оба;
    - /usr/libexec/dir320-sync-ftp.sh по cron раз в 2 минуты
      чинит расхождение, если пароль меняли через LuCI/SSH.
  passive 50000-50100

СЛУЖБЫ
------
  /etc/init.d/uhttpd      — веб-сервер (2 инстанса: :80 сайт, :8080 LuCI)
  /etc/init.d/vsftpd      — FTP (procd)
  /etc/init.d/firewall    — правила для 80/8080/21/50000-50100
  /etc/init.d/cron        — синхронизация FTP-пароля

ПОЛЕЗНЫЕ КОМАНДЫ
----------------
  sh /root/dir320-tui.sh              — установщик с псевдо-GUI (если скопирован)
  sh /root/dir320-tui.sh --status     — статус
  sh /root/dir320-tui.sh --detect     — кандидаты на очистку
  logread | grep uhttpd               — логи веб-сервера
  iwinfo                              — состояние Wi-Fi
  uci show uhttpd                     — конфиг веб-сервера

ОЧИСТКА СИСТЕМЫ
---------------
  Установщик → пункт 3. Алгоритм универсальный: пакеты-листья по графу
  зависимостей, защита запущенных служб/процессов, файлы без владельца,
  пустые каталоги. Экспертный режим (e) показывает системные пакеты —
  удаление требует ввода YES.

ПАРОЛИ
------
  root / LuCI / SSH / панель / FTP — один пароль.
  Wi-Fi (SSID/пароль/канал) — задаются в установщике (меню 2).
