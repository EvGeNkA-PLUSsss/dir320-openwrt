## 3.0.0

Универсальный релиз: установщик больше не привязан к модели и внутренним именам.

- меню сокращено до одного пункта **УСТАНОВИТЬ**: сначала полная автоматическая очистка, затем установка;
- определяются автоматически: модель/версия (для информации), LAN-IP, секции Wi-Fi (`wifi-device`/`wifi-iface`, включая анонимные), порт LuCI, интерфейсы;
- Wi-Fi: сохраняются текущие SSID/пароль, при отсутствии — генерируется пароль; без Wi-Fi-радио установка не падает;
- очистка: защита строится по факту — запущенные процессы, включённые службы, загруженные модули ядра, владельцы критичных файлов (Lua/nixio, uhttpd, dropbear, netifd, dnsmasq, Wi-Fi-утилиты) и `luci*`/`rpcd*`; удаляются пакеты-листья, файлы-сироты, пустые каталоги, кеши;
- порты: сайт — 80, админка/LuCI — текущий порт LuCI или свободный 8080+; всё настраивается через uci;
- Lua/nixio проверяются и при необходимости ставятся; shebang панели подставляется под найденный интерпретатор;
- файлы и названия обезличены: `openwrt-installer.sh`, `README-ROUTER.txt`, `owinst-sync-ftp.sh`.

# Changelog

## 2.1.1

- Панель: Wi-Fi теперь действительно настраивается и на «чистой» прошивке:
  - секции `wifi-device`/`wifi-iface` определяются автоматически (работает и с `radio0`, и с `radio1`/`wl0`, и с анонимными `@wifi-device[0]`);
  - если `/etc/config/wireless` отсутствует — он генерируется (`wifi config` с fallback на `wifi detect`);
  - если нет `wifi-iface` — создаётся;
  - результат каждого `uci set` проверяется, ошибка возвращается в интерфейс (раньше «применялось» молча);
  - при применении панель опрашивает состояние 3 раза, показывает реальный статус и подсказку, если Wi-Fi ещё не настроен;
  - добавлена кнопка «Обновить».
- Добавлены юнит-тесты Wi-Fi-логики: `tools/test_wifi.py` (нужен `pip install lupa`).
- Сборщик установщика пишет результат только с LF (иначе busybox ash не разбирает файл).
