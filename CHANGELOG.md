# Changelog

## 2.1.1

- Панель: Wi-Fi теперь действительно настраивается и на «чистой» прошивке:
  - секции `wifi-device`/`wifi-iface` определяются автоматически (работает и с `radio0`, и с `radio1`/`wl0`, и с анонимными `@wifi-device[0]`);
  - если `/etc/config/wireless` отсутствует — он генерируется (`wifi config` с fallback на `wifi detect`);
  - если нет `wifi-iface` — создаётся;
  - результат каждого `uci set` проверяется, ошибка возвращается в интерфейс (раньше «применялось» молча);
  - при применении панель опрашивает состояние 3 раза, показывает реальный статус и подсказку, если Wi-Fi ещё не настроен;
  - добавлена кнопка «Обновить».
- Добавлены юнит-тесты Wi-Fi-логики: `tools/test_wifi.py` (нужен `pip install lupa`).
- Сборщик установщика пишет результат только с LF (иначе busybox ash не разбирает файл).

## 2.1.0

- Первый публичный релиз: сайт, панель `/admin`, FTP, Wi-Fi, установщик с псевдо-GUI, универсальная очистка.
- Исправлена вкладка «Файлы» (обращение к удалённому элементу `root-ftp` ломало рендер).
